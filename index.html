How to Use Tonality Explorer

  • Select the initial number of sharps or flats in the Key Signature dropdown (the 7th degree automatically defaults to ?).
  • Modify specific note alterations using the interactive keyboard buttons below it.
  • If a note is uncertain, select the ? mark (e.g. G?).
  • All matching scales and tonalities will automatically appear below.
  • Tap the tick (✓) icon on any scale card to adopt its key signature.
